# しゅつどう！パズルレスキュー！

[ゲームを開く](https://ryo-ai-papa.github.io/puzzle-rescue/)

横画面で遊ぶ、4ステージ・16ピースのジグソーパズルです。

index.html にReact・CSS・4枚の画像を同梱。外部API、広告、課金、ログインはありません。

開発用React / TypeScript / Viteプロジェクトとテスト・公開手順は puzzle-rescue-source.zip に収録しています。

公開方式：GitHub Pages、mainブランチのルート。ゲームを更新するときは、開発プロジェクトで node scripts/build-offline.mjs を実行し、生成したHTMLをこのリポジトリの index.html に置き換えます。

24件の自動テストと本番ビルド確認済み。iPhone実機テストは未実施です。
